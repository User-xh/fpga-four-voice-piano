# 基于 FPGA 的多声部电子琴与音乐可视化系统 —— 技术文档（音频链部分）

> 阶段：纯 Icarus 仿真已闭环（按键→多键识别→4路复音 DDS→ADSR→混音→48k/16位 PCM→I2S）；
> 物理出声待 PCM5102A 接线；音乐可视化待启动。
> 本文为竞赛报告素材，所有参数均来自已仿真通过的工程源码。

## 1. 项目概述

以安路 PH1A180 FPGA（米联客 MLK-H10 / CK203 核心板）为平台，用纯数字方式实现一台可同时弹奏多个音的电子琴，并预留音乐可视化接口。

- **声音链**：4×4 矩阵键盘输入 → 多键识别 → 最多 4 路并行 DDS 合成 → ADSR 包络 → 混音归一化 → 48kHz/16bit PCM → I2S → 外置 PCM5102A DAC → 耳机/音箱。
- **可视化链（待做）**：音频样本/频谱送 HDMI 大屏或 SPI 小屏，做实时波形与频谱柱联动。
- 系统时钟：板载 25MHz（Y23，LVCMOS33）。

## 2. 系统总体架构（当前已仿真部分）

```
4×4矩阵键盘(C1~C4列,R1~R4行)
        │ 行列扫描, 内部上拉, 低有效
        ▼
 keyscan_multi  ── key_state[15:0] 16位按下位图(可多位同时为1)
        │
        ▼
 voice_assign   ── 按优先级把位图分给最多4个voice槽, 输出 v_gate[3:0]+v_fcw
        │
   ┌────┼─────────┬─────────┐
   ▼    ▼         ▼         ▼
 voice_chan0..3 = dds_nco + adsr_env(去直流×gain/256, 钳位12位)
   │    │         │         │
   └────┴────┬────┴─────────┘
             ▼
          mixer  去直流→只加有效路→/4归一化→加回2048 (12位, 防削波)
             ▼
          audio_out  去直流<<4 → 16位有符号, 25M/520≈48.08k锁存(左右同值)
             ▼
          i2s_tx   32位槽/16位放高/MSB先出/WS低左高右 → BCK/LRCK/DIN
             ▼
        [待接] PCM5102A DAC → 耳机
```

## 4. 核心模块原理

### 4.1 DDS / NCO 数字频率合成
DDS 用"相位累加 + 查表"产生正弦，不依赖模拟振荡器：

1. 32位相位累加器每时钟加一次频率字 FCW；
2. 取累加器高8位作地址，查 256 点 12 位正弦表（中点2048，峰4095，谷1）；
3. 输出 12 位正弦样本。

频率关系：

```
f_out = FCW × Fs / 2^N
=> FCW = f_out × 2^32 / Fs        (Fs=25MHz, N=32)
```

FCW 越大，相位累加越快，波形越密、音越高。`dds_sin.v` 为固定FCW单音版（已由VCD验证中点/峰谷）；`dds_nco.v` 改为 FCW 外部动态输入，换键即换音高。

键位映射（矩阵）：bit=行号×4+列号，R1=bit0~3，R2=bit4~7，R3=bit8~11，R4=bit12~15。

### 4.3 4×4 矩阵扫描（keyscan_multi）
逐行拉低、读列：当前扫描行输出0、其余行1；列空闲为1（内部上拉），按下为0。
每拍只刷新当前行4位、其余行保持，因此**多位可同时为1**，输出16位位图供复音使用。
（注：本多键版当前未做专门软件消抖，板级联调时补充计数消抖。）

### 4.4 复音分配（voice_assign）
遍历16位位图，低位键优先，依次填入 voice0~3，最多同时响4个音；输出每路 v_gate 与对应 FCW，超过4键忽略。

### 4.5 并行DDS + 混音归一化（mixer）
4路 dds_nco 并行独立振荡。混音时先对每路去直流(样本-2048)，只累加 gate 有效路，再算术右移2位(/4)归一化，最后加回中点2048，保证总和不超出12位范围、不削波。

### 4.6 ADSR 包络（adsr_env + voice_chan）
每个voice一个四段状态机：

```
IDLE → ATTACK(增益0线性升到255) → DECAY(降到SUSTAIN=160)
     → SUSTAIN(按住保持160) → [松手]RELEASE(降到0) → IDLE
```

`voice_chan` = dds_nco + adsr_env：样本去直流后乘 gain/256，再加回直流并钳位到0~4095，使音量随包络平滑起伏（起音柔和、松有余韵）。

### 4.7 采样与PCM封装（audio_out）
mixed 去直流后左移4位放大成16位有符号；25MHz/520≈48.08kHz 产生采样使能锁存一个样本，左右声道送同一值（单声道）。

### 4.8 I2S 发送（i2s_tx）
- BCK=25M/8=3.125MHz；LRCK(WS)=BCK/64≈48.8kHz；
- 一帧=左32位槽+右32位槽，16位有效数据放槽的高16位、低16补0，MSB先出；
- WS=0左声道、WS=1右声道。

## 7. 已知简化与待办（诚实清单）
1. **混音固定/4**：只按一个键时音量偏小，板级可改为按实际发声路数归一化；
2. **ADSR时间常数**：当前按系统时钟节拍推进，真实毫秒起音/余韵需改由48k采样节拍驱动或调步长；
3. **多键扫描未做专门消抖**，板级补计数消抖；
4. **I2S串行位时序**：仿真只核对槽数据与声道归属，DIN逐位MSB由固定左移保证，精确位时序待真DAC用逻辑分析仪核对；
5. **可视化未启动**：需先定 HDMI 1080P 大屏 还是 SPI 小屏(SSD1306/ST7789/ILI9341)，再做波形/频谱联动；
6. **物理板级联调未做**：PCM5102A、杜邦线未购，键盘未接线；
7. 单声道（左右同值），未做立体声声像。
