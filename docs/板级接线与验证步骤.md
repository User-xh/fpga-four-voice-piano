# MLK-H10 多声部电子琴+可视化 板级接线与验证步骤（直连实测版）

> 顶层模块 top_system；bit：`my_projects\my_dds\my_dds_Runs\best_result\my_dds.bit`
> 下载方式：唐IDE BitWriter → PROGRAM_SRAM（易失，断电消失，调试用；固化才用 PROGRAM_FLASH）。
> 验证顺序：**A 烧录 → B OLED 点亮（不接键盘也有画面）→ C DAC 出声 → D 键盘联调**。每步成功再接下一步。

## 一、J14（CEP 2×20 排针）针号总图（已对照底板原理图逐针复核 2026-10-30）

排针面对丝印、缺口朝自己：左列奇数针 1/3/5…39，右列偶数针 2/4/6…40。

| J14针 | 网络/FPGA脚 | 用途 | J14针 | 网络/FPGA脚 | 用途 |
|---|---|---|---|---|---|
| **1** | VCC_CEP = **3.3V** | 给模块VCC供电 | **2** | **GND** | 公共地 |
| 3 | AE6 | 空闲 | 4 | AE5 | 空闲 |
| 5 | AD6 | 空闲 | 6 | AD5 | 空闲 |
| 7 | AC4 col_in[0] | 键盘C1 | 8 | AC3 col_in[1] | 键盘C2 |
| 9 | V2 col_in[2] | 键盘C3 | 10 | V1 col_in[3] | 键盘C4 |
| 11 | Y6 row_out[0] | 键盘R1 | 12 | Y5 row_out[1] | 键盘R2 |
| 13 | AF5 row_out[2] | 键盘R3 | 14 | AF4 row_out[3] | 键盘R4 |
| 15 | AF3 bck | DAC BCK | 16 | AF2 lrck | DAC LRCK/WS |
| 17 | AE3 din | DAC DIN | 18 | AE2 oled_scl | OLED SCL(I2C时钟) |
| 19 | AD1 oled_sda | OLED SDA(I2C数据) | 20 | AE1 | 空闲（原DC已弃用，勿接） |
| 21 | AD4 | 空闲（原CS#已弃用，勿接） | 22~38 | 各空闲信号 | 备用 |

> 关键：针1=3.3V、针2=GND，模块电源直接从排针取。39/40 不要接线。
> OLED 现为 **4脚 I2C**，只用针18(SCL)、针19(SDA)两根信号线；针20/21 不再接线。

## 二、电平说明（务必先看）

- J14 信号脚属 BANK33，VCCO=1.8V，FPGA 高电平≈1.8V；DAC/OLED 为 3.3V 器件，手册高电平阈值约 2.3~2.4V。
- 本版先**直连实测**：模块 VCC 用针1 的 3.3V，信号直接连。若 OLED 花屏/不亮、DAC 无声，即确认电平不足，下一步加 1.8→3.3 电平转换模块。
- 注意：OLED 现为 I2C（SCL/SDA 双向线），电平转换需选**双向**器件（如 TCA9406 / TXS0108E），与单向 SPI 转换选型不同；DAC 为单向。先直连实测，不亮再评估。
- 键盘是无源开关，不涉及电平阈值，可直接接。

## 三、阶段 A：烧录（先不接任何外设）

1. 板子上电、AL-Link 下载器连好；J14 排针先不插杜邦线。
2. 唐IDE 打开 BitWriter，模式选 **PROGRAM_SRAM**。
3. 选 bit：`D:\FPGA-2\my_projects\my_dds\my_dds_Runs\best_result\my_dds.bit`，下载。
4. 预期：下载成功提示。**此时板上灯不亮、无声音无画面都正常**——本工程没驱动板载 LED，且外设未接。

## 四、阶段 B：OLED 单测（SSD1306 4脚 I2C）

断电后接线（模块丝印名 → J14针，共4根线）：

| OLED模块脚（以丝印为准） | 接到 J14 | 说明 |
|---|---|---|
| GND | 针2 GND | 公共地 |
| VCC / VDD | 针1 3.3V | 供电（模块板载一般带上拉，无需外接） |
| SCL | 针18 oled_scl | I2C 时钟 |
| SDA | 针19 oled_sda | I2C 数据 |

- 本屏**没有 DC、CS、RST 脚**，针20、针21 不接；不要把 SPI 时代的 DC/CS 线接上。
- 从机写地址当前为 `0x7A`（7位地址0x3D，SA0=1）；若四根线全对仍全黑，把 `i2c_master.v` 参数 `ADDR_W` 由 `8'h7A` 改回 `8'h78`（对应0x3C）重新综合，两个地址各试一次。
- 上电重新 PROGRAM_SRAM 一次。
- 预期：初始化成功，上半屏一条水平中线（波形静止居中），下半屏16根空柱（无按键时为0高度）。
- 异常：全黑=没供电/SCL或SDA接反；花屏/乱码=电平不足或地址不对；先核对4根线序，仍异常则判定需双向电平转换。

## 五、阶段 C：DAC 单测出声（PCM5102A）

OLED 正常后再加 DAC（断电接线）：

| PCM5102A模块脚（以丝印为准） | 接到 J14 |
|---|---|
| VIN / VCC / DVDD | 针1 3.3V |
| GND | 针2 GND |
| BCK / BCLK | 针15 bck |
| LRCK / WS / LRCK | 针16 lrck |
| DIN / DATA / DSDIN | 针17 din |
| SCK / MCK | 悬空不接（内部PLL，无需主时钟） |
| MUTE / SMUTE / FMT / FLT | 悬空（模块一般已处理；若无声且模块有MUTE脚，按丝印接高电平使能） |

- 耳机插入模块 3.5mm 座。
- 此时未接键盘，无按键=静音属正常；出声验证在阶段D按键时完成。
- 若接键盘后仍完全无声、且OLED正常，优先怀疑 DAC 电平不足，加电平转换。

## 六、阶段 D：键盘联调（4×4 无源矩阵，无电源脚）

| 键盘丝印 | 接到 J14 | 键盘丝印 | 接到 J14 |
|---|---|---|---|
| C1 | 针7 | R1 | 针11 |
| C2 | 针8 | R2 | 针12 |
| C3 | 针9 | R3 | 针13 |
| C4 | 针10 | R4 | 针14 |

- 键盘无 VCC/GND，不接电源；若模块行列丝印与上表相反导致按键错乱，把 C/R 整体对调即可。
- 键位（行→键号→音符）：
  - R1(针11)：键0 C4 / 键1 C#4 / 键2 D4 / 键3 D#4
  - R2(针12)：键4 E4 / 键5 F4 / 键6 F#4 / 键7 G4
  - R3(针13)：键8 G#4 / 键9 A4 / 键10 A#4 / 键11 B4
  - R4(针14)：键12 C5 / 键13 C#5 / 键14 D5 / 键15 D#5
- 预期：按键出声、松手约200ms内渐弱；同时按2~4键为复音；OLED下半屏对应柱随按下升高、松手回落，上半屏波形滚动。

## 七、常见排查

| 现象 | 优先排查 |
|---|---|
| 下载后个别键/外设无反应 | 先重新 PROGRAM_SRAM 下载一次（历史出现过需重下才全响应） |
| OLED 全黑 | VCC/GND、SCL(针18)/SDA(针19)线序；从机地址是否需改0x7A；重新下载一次 |
| OLED 花屏/乱码 | 电平不足（1.8V→3.3V，I2C需双向转换模块）；其次SCL/SDA接反 |
| DAC 完全无声 | BCK/LRCK/DIN 线序；MUTE脚是否使能；电平不足加转换；耳机音量 |
| 按键错乱/串键 | 行列丝印接反，C/R对调；消抖由FPGA完成无需外接电阻 |
| 单键声音偏小/多键削波 | 混音已按路数动态归一化，若仍异常回查 mixer 仿真 |
